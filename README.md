# C++ 短链服务后端 (Short URL Server)

基于 C++17 开发的高性能 Web 短链生成与跳转服务。

## 🛠️ 技术栈
- **开发语言**：C++17
- **Web 框架**：cpp-httplib
- **存储与缓存**：Redis (redis-plus-plus)
- **日志系统**：spdlog
- **构建工具**：CMake

## ✨ 核心功能与亮点
1. **短链生成与跳转**：长短链映射，302 重定向。
2. **高并发限流**：基于 Redis 的 `INCR` 与 `EXPIRE` 实现固定窗口限流（单 IP 限制 60 秒 5 次），有效防止恶意刷接口。
3. **工程化架构**：路由层与业务层解耦，使用 CMake 构建，引入 spdlog 实现控制台与文件双端日志记录。
4. **并发安全**：使用 `std::mutex` 保证多线程环境下的 Redis 客户端线程安全。
